# 美食推荐插件

基于 AstrBot 框架的美食推荐插件，向机器人发送特定消息即可获得随机美食推荐及详细做法。

---

## 功能介绍

- **随机推荐**：随机推荐一道美食并提供详细做法
- **分类筛选**：十大分类（早餐/荤菜/素菜/水产/汤羹/主食/甜品/饮品/酱料/半成品），并兼容「早餐/午餐/晚餐/夜宵」口语
- **菜谱查询**：根据菜名查询具体做法
- **菜谱总览**：查看已收录的全部菜品列表
- **自然语言触发**：无需严格命令，口语化即可触发

---

## 使用方法

### 安装

将 `astrbot_plugin_food_recommend` 文件夹放入 AstrBot 插件目录，在 WebUI「插件管理」页面启用。

### 触发方式

#### 方式一：自然语言（推荐）

直接发送包含关键词的消息即可触发：

- `吃什么` / `吃啥` / `今天吃什么` / `推荐美食` / `不知道吃什么`

指定餐类或分类：

- `早餐吃什么` / `午餐吃啥` / `晚餐推荐` / `夜宵吃什么`
- `推荐个荤菜` / `来碗汤` / `想吃甜点` / `推荐主食`

#### 方式二：命令

| 命令 | 别名 | 说明 |
|------|------|------|
| `/吃什么` | `/吃啥` `/food` `/今天吃什么` `/推荐食物` | 随机推荐 |
| `/吃什么 早餐` | — | 按餐类推荐（早餐/午餐/晚餐/夜宵）|
| `/吃什么 荤菜` | — | 按分类推荐（荤菜/素菜/水产/汤羹/主食/甜品/饮品/酱料/半成品）|
| `/怎么做 菜名` | `/howto` `/食谱` `/做法` `/recipe` | 查询指定菜品做法 |
| `/菜单` | `/menu` `/全部菜谱` `/美食列表` | 列出所有菜品 |

```
└── README.md
```

---

## 更新数据

HowToCook 持续更新，可随时一键重建本地数据（会自动克隆、解析、清理）：

```bash
python build_food_data.py
```

> 插件回复由代码固定生成，触发后调用 `event.stop_event()` 阻止事件继续传播，不会交由 LLM 二次改写。
